# The Liver and the Stars

An interactive website about Babylonian divination. The visitor finds the marks on a hand-drawn sheep's liver, reads the night sky, and receives a fortune weighed from both.

Journey: liver → liver reading → sky → sky reading → overall summary.

## Run locally

Open `index.html` in a browser, or:

    npm install
    npm start

## Deploy on Railway

Railway runs `npm start`, which serves the folder on the port Railway provides. No build step and no environment variables are needed.

## Draft status

The old-voice omen lines are paraphrases in the style of the omen collections, not quotations. The mark rule (Hole and Weapon) and the constellation drawings are simplified. All are placeholders until checked sources replace them.
